Repositorio central para el almacenamiento, versionado y control de todos los documentos, artefactos, evidencias y entregables correspondientes al **Proyecto Integrador** de la materia de Testing y Aseguramiento de Calidad (TQA).

---

## 🎯 Propósito del Repositorio
Este espacio alberga la documentación formal del proyecto, incluyendo:
- Especificación de requerimientos funcionales y no funcionales.
- Planes de pruebas (Test Plan) y matrices de trazabilidad.
- Evidencias de ejecución de pruebas manuales y validaciones.
- Informes de hitos y presentaciones de avance.

---

## 📁 Estructura del Repositorio

```text
Proyecto-Integrador-TQA/
├── docs/                    # Documentos formales, especificaciones y planes de prueba
│   └── plan-de-pruebas.md   # Estructura inicial del Plan de Pruebas
├── entregables/             # Informes de hitos, diapositivas y entregas formales
├── evidencias/              # Capturas, actas y registros de ejecución de pruebas
├── .gitignore               # Archivos excluidos del control de versiones
└── README.md                # Descripción general del repositorio
```

## 📌 Convenciones de Commits
Para mantener un historial limpio y estructurado, se utilizan las convenciones de [Conventional Commits](https://www.conventionalcommits.org/):
- `docs:` Modificaciones o adiciones en documentación.
- `feat:` Nuevos artefactos o plantillas.
- `test:` Adición de casos de prueba o matrices.
- `fix:` Correcciones en entregables.
